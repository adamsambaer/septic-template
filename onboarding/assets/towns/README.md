# Town lookup data

Generated by `scripts/build-zip-data.mjs` from the GeoNames US postal code
export, licensed **CC BY 4.0**. Attribution: GeoNames,
https://download.geonames.org/export/zip/.

One file per two-digit ZIP prefix:

- `z`: zip to [lat, lng, town, state]. The coordinates place the ZIP for the
  distance sort; the town and state are the client's own address, which Sapt
  requires on the site-settings item.
- `t`: every town within 35 miles of any ZIP in the shard, as
  [name, county, state, lat, lng]. Computed against every ZIP in the shard, so a
  ZIP on the edge of a prefix still sees its neighbours across the line.

Do not edit by hand. Regenerate:

    curl -L -o US.zip https://download.geonames.org/export/zip/US.zip
    unzip US.zip
    node scripts/build-zip-data.mjs US.txt
