# Town lookup data

Generated by `scripts/build-zip-data.mjs` from the GeoNames US postal code
export, which is licensed **CC BY 4.0**. Attribution: GeoNames,
https://download.geonames.org/export/zip/.

One file per two-digit ZIP prefix. Each holds every ZIP starting with those
digits (`z`: zip to lat/lng) and every town within 35 miles of any of them
(`t`: name, county, state, lat, lng), so a ZIP on the edge of a prefix still
sees its neighbours and the browser fetches one file of about 30KB.

Regenerate:

    curl -L -o US.zip https://download.geonames.org/export/zip/US.zip
    unzip US.zip
    node scripts/build-zip-data.mjs US.txt
